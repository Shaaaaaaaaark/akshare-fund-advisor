# 财务、行业与基金质量候选接口审计

审计版本：`akshare==1.18.64`

审计日期：2026-08-04

代表输入：

```text
A 股：600519
普通基金：000001
ETF：510300
财务报告期：20251231
基金披露年份：2025
行业 PE 日期：20260804
```

本文记录候选接口的发现审计，不表示这些接口已经进入生产 Skill、MCP 或 Agent。当前生产
工具数量仍为九个 Fund MCP 工具和三个 Web MCP 工具。

## 1. 审计方法

每个候选接口执行以下检查：

1. 从锁定版本安装包读取真实函数签名、源码模块和文档；
2. 对代表标的执行限时真实调用，不使用 Mock 或示例行情；
3. 校验返回值是非空 DataFrame、列名无重复、必需字段存在；
4. 记录参数、耗时、行数、列名、日期覆盖和 `frame_sha256`；
5. 检查代码唯一性、逐行时效、关键字段缺失和多对多关系；
6. 对失败接口重试，区分稳定契约缺口与临时上游故障；
7. 按 `adopt`、`conditional`、`reject` 分级。

复现入口：

```bash
export SKILL_DIR="$PWD/skills/akshare-fund-advisor"
AKSHARE_FUND_VENV="$PWD/.venv-agent" \
  "$PWD/.venv-agent/bin/python" \
  "$SKILL_DIR/scripts/audit_quality_interfaces.py" \
  --group all \
  --as-of 20260804 \
  --report-date 20251231 \
  --fund-year 2025
```

脚本固定返回 `discovery_only=true`，不会修改生产工具或生成筛选结论。

## 2. 总体结果

共盘点 24 个候选接口：

| 分组 | 候选数 | 至少一次真实调用通过 | 当前失败或不适合 |
| --- | ---: | ---: | ---: |
| 个股财务 | 8 | 7 | 1 |
| 行业 | 6 | 3 | 3 |
| 基金质量 | 10 | 8 | 2 |
| 合计 | 24 | 18 | 6 |

“通过”只说明本次调用和 Schema 校验成功，不代表接口将永久可用；“不适合”也可能是接口

## 3. 个股财务接口

### 3.1 建议用于第一阶段

| 接口 | 用途 | 本次结果 | 接入约束 |
| --- | --- | --- | --- |
| `stock_yjbb_em` | 全市场年度财务横截面初筛 | 通过 | 只保留代码前缀 `0/3/6`；逐行校验公告日期和缺失字段 |
| `stock_financial_analysis_indicator_em` | 候选股票主要财务指标 | 通过 | 使用带市场后缀代码；按报告期去重；只取已登记字段 |
| `stock_balance_sheet_by_report_em` | 资产、负债、商誉 | 通过 | 只读取明确字段，不把空值补零 |
| `stock_profit_sheet_by_report_em` | 收入、利润、扣非利润 | 通过 | 区分累计报告期和单季度，不混算 |
| `stock_cash_flow_sheet_by_report_em` | 经营现金流与利润质量 | 通过 | 经营现金流和净利润必须来自同报告期 |
| `stock_zygc_em` | 主营构成和集中度 | 通过 | 只使用同一报告日期和同一分类类型 |

`stock_yjbb_em(date="20251231")` 本次返回 11517 个唯一六位代码，其中：

- 沪深 `0/3/6` 前缀共 5213 个唯一代码；
- 北交所/其他市场主要集中在 `4/8` 前缀，不能混入当前沪深 A 股能力；
- 沪深记录只有 3 条缺少“所处行业”；
- 以审计 `as_of=2026-08-04` 计算，有 10 条公告日期位于未来，必须拒绝；
- ROE、毛利率和收入增速存在缺失，筛选结果必须输出 `unknown_rules`。

### 3.2 备用或暂不采用

| 接口 | 分级 | 原因 |
| --- | --- | --- |
| `stock_financial_abstract_new_ths` | conditional | 长表结构可用，但指标名和字段集合动态变化，只适合作为备用核验源 |
| `stock_individual_info_em` | reject | 首次调用出现列数不匹配，重试又被上游断连，当前不能作为行业真值源 |

### 3.3 财务字段边界

第一阶段只允许从审计字段构造确定性维度：

```text
盈利：ROE、ROIC、营业收入、归母净利润、扣非归母净利润
成长：营业收入同比、净利润同比
现金流：经营活动现金流、经营现金流/净利润
财务安全：总资产、总负债、资产负债率、商誉
主营结构：主营收入占比、主营利润占比
```

公式由代码实现；模型不得计算、补值或根据公司名称猜测行业和业务。

## 4. 行业接口

### 4.1 可行的同口径链路

| 接口 | 用途 | 本次结果 | 约束 |
| --- | --- | --- | --- |
| `stock_industry_change_cninfo` | 个股行业归属历史 | 首次失败，重试通过 | 必须按明确分类标准过滤并有限重试 |
| `stock_industry_pe_ratio_cninfo` | 证监会行业静态 PE | 通过 | 只能和同为证监会分类的个股行业编码关联 |

代表股票在“证监会行业分类标准”下的行业编码和行业名称，都能与
`stock_industry_pe_ratio_cninfo(symbol="证监会行业分类")` 精确匹配。

禁止：

- 将东方财富“所处行业”直接拼接到证监会行业 PE；
- 将申万、巨潮、中证和证监会行业名称按文本近似合并；
- 行业归属接口失败后根据公司名称猜行业；
- 把行业静态 PE 写成个股 PE TTM。

### 4.2 当前不作为主路径

| 接口 | 分级 | 本次情况 |
| --- | --- | --- |
| `stock_board_industry_name_em` | reject | 两次调用均被上游断开连接 |
| `stock_board_industry_cons_em` | reject | 两次调用均被上游断开连接 |
| `stock_industry_category_cninfo` | reject | 两次出现非 JSON 响应 |
| `stock_board_industry_summary_ths` | reject | Schema 可用，但只是实时行情概览，不能完成个股行业映射或质量分析 |

个股财务横截面对比可优先使用 `stock_yjbb_em` 同一张表中的“所处行业”，因为股票字段和
行业字段来自同一接口、同一报告期。行业估值则必须走巨潮的同分类链路。

## 5. 基金质量接口

### 5.1 建议用于第一阶段

| 接口 | 用途 | 本次结果 | 接入约束 |
| --- | --- | --- | --- |
| `fund_open_fund_rank_em` | 按类型构建基金候选池 | 通过 | 逐行校验日期；不同基金类型和份额不得混排 |
| `fund_rating_all` | 第三方评级 | 通过 | 评级只是一个维度，不代表未来表现 |
| `fund_portfolio_industry_allocation_em` | 报告期行业配置 | 通过 | 披露数据不是实时仓位 |
| `fund_manager_em` | 基金与现任经理关系 | 通过 | 多对多聚合；从业时间单位需确认；最佳回报不作为经理评分 |
| `fund_individual_achievement_xq` | 阶段业绩和同类排名辅助核验 | 通过 | 同类排名是分数字符串；先解析分子和分母；源收益不覆盖本地确定性收益 |

`fund_open_fund_rank_em(symbol="全部")` 本次返回 20072 个唯一基金代码，但存在：

- 1 条无效日期；
- 相对 `as_of=2026-08-04` 大量记录日期更晚，必须按请求日期拒绝；
- 近 1/2/3 年收益分别存在不同数量的缺失，不能把缺失值当零；
- 返回结果不含稳定的份额类别字段，筛选后仍需用基金目录确认类型和 A/C 类。

`fund_manager_em()` 本次返回 35512 条基金—经理关系：

- 现任基金代码不是唯一键；
- 15786 行属于重复基金代码，说明同一基金可能有多位经理；
- 经理字段必须先按基金代码聚合，不能把单行“最佳回报”当基金或经理总分。

### 5.2 暂不采用

| 接口 | 分级 | 原因 |
| --- | --- | --- |
| `fund_individual_analysis_xq` | reject | 上游字段为 `volatility_rank` / `sharpe_rank`，AKShare 却重命名为波动率/夏普比率，语义未确认 |
| `fund_scale_change_em` | reject | 返回基金市场整体规模变化，不是单基金规模历史 |
| `fund_hold_structure_em` | reject | 返回基金市场整体持有人结构，不是单基金持有人结构 |
| `fund_portfolio_change_em` | reject | 重试后仍出现解码错误 |
| `fund_etf_fund_info_em` | reject | 重试后仍出现返回列数不匹配 |

当前 AKShare 候选中尚未找到经过审计的：

- 单基金规模变化历史；
- 单基金经理在该产品上的任职起止日期；
- 指数基金跟踪误差和跟踪差异；
- 可直接用于主动基金质量的稳定夏普比率源。

这些字段必须保持缺失，不能从名称、评级或收益率推断。

## 6. 推荐的筛选数据链路

### 股票

```text
stock_yjbb_em
  -> 过滤沪深 0/3/6
  -> 校验报告期、公告日期和字段覆盖
  -> 按明确规则形成候选
  -> 三大报表 + 主要指标 + 主营构成深度核验
  -> 同分类行业对比
```

### 基金

```text
fund_open_fund_rank_em(按基金类型)
  -> 基金目录确认类型和份额
  -> 逐行时效与历史长度门禁
  -> 本地净值序列重算收益、波动和回撤
  -> 评级、经理关系和披露行业配置补充
```

第一版不生成综合 AI 分数。每个候选只返回：

```text
passed_rules
failed_rules
unknown_rules
metric_basis
as_of
audit_ref
```

“优秀”由版本化筛选规则定义，模型只能解释通过和未通过的条件。
