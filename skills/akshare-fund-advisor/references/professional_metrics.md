# 普通投资者基金定投指标框架

本框架用于回答三个问题：

1. 这只基金是否适合长期定投？
2. 当前估值和风险处于什么位置？
3. 投资者能否承受持有过程，而不是只看最终收益？

指标不能替代投资者自身条件。任何定投建议之前，必须先确认：

- 资金至少多久不用。
- 每期可持续投入的现金流。
- 是否已有 3-6 个月应急资金。
- 当前和目标资产仓位。
- 最大可承受回撤。
- 投资目标是保值、稳健增值还是长期权益增长。

## 指标优先级

### 第一层：产品是否合适

| 指标 | 作用 | 重点 |
| --- | --- | --- |
| 基金类型与投资范围 | 确认底层风险来自股票、债券、行业或海外市场 | 类型选错，后续择时没有意义 |
| 跟踪标的/业绩基准 | 明确基金真正投资什么 | 指数名称必须精确匹配，子指数不能映射为宽基 |
| 成立时间 | 判断是否有足够历史样本 | 新基金历史数据不足不等于低风险 |
| 管理费、托管费 | 长期确定性成本 | 同类产品中费用越低越有优势 |
| 申购、赎回规则 | 避免短期赎回费、封闭期和限购 | 最高费率不等于投资者实际费率 |
| 份额规模/净资产规模 | 观察清盘和流动性风险 | 份额规模不等于净资产，不能混用 |

### 第二层：投资者能否拿得住

| 指标 | 解释 |
| --- | --- |
| 年化收益 | 观察区间首尾值折算的复合年化增长，不代表未来收益 |
| 年化波动率 | 日收益波动的年化值，衡量价格上下波动 |
| 下行波动率 | 只惩罚负收益，更接近投资者对亏损波动的感受 |
| 最大回撤 | 历史峰值到后续谷底的最大跌幅 |
| 回撤峰值/谷值/修复日期 | 告诉投资者亏损发生在哪、多久才回本 |
| 最长水下期 | 净值低于历史高点的最长持续时间 |
| Calmar 比率 | 年化收益除以最大回撤绝对值，仅用于同类、同周期比较 |
| 月度正收益比例 | 历史月份中上涨月份的占比 |
| 滚动 250 日收益分布 | 观察不同买入时点的一年持有结果分散程度 |

不使用单一夏普比率作核心结论。夏普依赖无风险利率和计算口径，若数据源没有明确披露口径，只能作为外部参考。

### 第三层：指数基金质量

| 指标 | 重要性 |
| --- | --- |
| 跟踪误差 | 衡量每日收益相对指数的波动偏差 |
| 跟踪差异 | 衡量长期累计收益相对指数落后或领先多少 |
| 管理费与托管费 | 长期确定性拖累 |
| 规模与成交额 | 关系到清盘风险、流动性和买卖冲击 |
| ETF 折溢价 | 场内价格相对 IOPV/净值的偏离 |
| 指数估值 | 判断底层指数的历史相对估值，不是基金自身估值 |

AKShare 当前链路不能稳定、完整地提供所有指数的跟踪误差和跟踪差异。缺失时必须明确标记，不能用基金收益率或名称猜测。

### 第四层：主动基金质量

| 指标 | 重要性 |
| --- | --- |
| 基金经理及任职变化 | 经理变化可能导致策略和风格切换 |
| 相对业绩基准超额收益 | 判断主动管理是否长期创造价值 |
| 前十大持仓集中度 | 衡量个股集中风险 |
| 行业集中度 | 衡量赛道和风格风险 |
| 资产配置 | 观察股票、债券和现金仓位 |
| 规模变化 | 规模过小有清盘风险，过大可能影响策略容量 |

持仓和资产配置来自定期报告，不是实时仓位。必须显示报告期。

## 历史 PE 曲线

### 应统计什么

历史 PE 图默认使用底层指数的加权 `PE TTM`：

- 完整日频曲线。
- 当前 PE。
- 3 年、5 年、10 年和可用最长区间分位。
- 各区间中位数、均值、20%/80% 分位值、最高和最低。
- 当前值相对中位数和均值的位置。
- 数据起止日期、样本数和数据源。
- PB 历史曲线作为独立辅助指标。

### 正确解释顺序

1. 先确认基金精确跟踪哪个指数。
2. 查看 PE TTM 当前值和长期历史分位。
3. 查看 3/5/10 年分位是否一致，避免只选有利区间。
4. 中位数和 20%/80% 分位优先于均值 ±1 标准差。
5. 再看 PB、盈利趋势、利率环境和指数成分变化。
6. 最后结合基金费率、跟踪误差和场内溢价。

### 为什么不把 PE 和 PB 平均

- PE 反映价格相对盈利。
- PB 反映价格相对账面净资产。
- 两者适用行业和经济含义不同。
- 金融、重资产和周期行业通常更重视 PB。
- 轻资产成长行业的 PB 可比性较弱。

因此 Skill 禁止生成“PE/PB 综合分位”。PE 和 PB 必须分别展示和解释。

### 历史 PE 的局限

- PE 低可能来自盈利周期高点，不一定便宜。
- PE 高可能来自短期利润下滑，不一定代表长期高估。
- 亏损公司和异常盈利会影响指数 PE 口径。
- 指数成分会调整，十年前和当前的产业结构可能不同。
- 历史分位只说明过去位置，不给出未来收益概率。
- 行业主题指数必须结合行业景气和盈利周期，不能仅凭低 PE 定投。

## 定投规则

专业定投的基础是固定现金流和目标资产配置，不是预测最低点。

默认动作只分为：

| 动作 | 条件 |
| --- | --- |
| 基础定投 | 产品适合、资金期限足够、仓位未超目标 |
| 减量或等待 | PE 长期高分位、仓位已高或资金期限缩短 |
| 暂停当前场内渠道 | ETF 溢价明显，但可比较对应场外基金或等待溢价回落 |
| 小幅估值倾斜 | PE 长期低分位、产品逻辑未变、仓位低于目标且趋势不再恶化 |
| 停止机械定投并复核 | 经理/策略/指数变化，或家庭现金流和风险承受能力变化 |

Skill 不输出机械的 `0.5/1.5 倍`金额。具体金额必须由用户的每期预算、目标仓位和最大回撤约束确定。

场内 ETF 使用独立风险控制：仅当行情日期有效且按 `(价格 - IOPV) / IOPV` 计算的溢价率 `> 5%` 时，暂停当前场内渠道。该规则不表示基金本身高估，也不等于卖出信号。

## Skill 输出要求

`analyze` 至少输出：

- `fund_profile`：产品、经理、基准、原始费用和规模文本。
- `fund_profile.derived`：基金年龄、已知持续费率、份额规模解析值。
- `metrics`：收益、波动、回撤和历史位置。
- `metrics.holding_experience`：持有体验统计。
- `index_valuation`：精确匹配成功时的 PE/PB。
- `portfolio_snapshot`：可获得时的资产配置和持仓集中度。
- `market_snapshot`：ETF 实时价格、IOPV和溢价。
- `metric_coverage`：已统计和缺失指标。
- `dca_plan`：定投动作区间，不给伪精确金额。
- `investor_inputs_required`：给出具体计划前必须补充的信息。
